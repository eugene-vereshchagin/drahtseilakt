# 测试玩家怎样驾驶：规则

测试玩家的运行是关卡可以通关的证明，它们的视频会被观看。所以它像一个自信、稳健的玩家那样驾驶：走在跑道中间，以均匀、适中的速度，不走竞速路线，也不在显而易见的地方犹豫。只在关卡要求的地方减速（狭窄处、时机）。这些规则说明怎样做；每个关卡的路线（`hints/Level_NN.route`）说明在哪里做。它们所依据的机制见 [autopilot.md](autopilot.md)。

## 节奏

- **按地面定巡航速度。** 在轨道或窄道上适中（每秒 6 个单位），在宽阔地面上更快（最多 10，随地面宽度）。更快有代价；在没有需要等待之处慢于其一半也有代价。
- **不走走停停。** 提示中的点是滚过（`pass`），而不是停在上面（`goto`），除非下一步需要球静止且就位：冲向靶子的助跑、冲撞的起点、秋千的边缘。
- **卡住的时间短。** 两秒没有推进，测试玩家就尝试机动。跟随玩家的回放时以玩家的节奏为准（四秒，原来的操控）：玩家在那里等待可能是有原因的。

## 球从不停下的地方

- **轨道尽头和门槛。** 路线从轨道走上地面，或上一个小台阶时，球保持动量：在那里被挡住片刻，就稍微后退，再带着速度越过。
- **变球器。** 在途中带着速度滚入；游戏在变形时托住球，这不是玩家的停顿。被变球器的边沿挡住时，球立即滚入。
- **路线要越过的缺口。** 立即助跑越过，而不是在边缘站着。
- **直道、弯道、沙袋和摆动的部件（路通时）。** 不犹豫；只在活动部件挡在路上时才等它。

## 轨道和原木

- **一串点就是一条线。** 每个 `pass` 都让球保持在从上一个点出发的线上，所以沿轨道或窄道写的一串点会沿着它们走，而不会抄近路。
- **上下叠放的轨道对**（球在下方轨道上滚动，靠着上方轨道）：沿它们用 `press`，向上方轨道偏移，先在轨道对的起点对准；到轨道对尽头时速度要足以过渡到下一对。
- **波浪原木。** 停在波谷里的球爬不出来，石球更不行：在波浪原木上球保持速度（高速 `press`），从平躺在上面的变球器之间穿过。

## 球停下或等待的地方

- **秋千和升降台**：在边缘静止，直到在运行副本上找到的时机（`cross`）。
- **靶子**：助跑前精确对准（`hold`），然后高速撞入靶盘并继续推（先 `press` 再 `push`）：只碰到靶盘的球会让桥保持竖起。
- **要撞下去的箱子**：每次冲撞都从同一处助跑，撞后刹车，以免球跟着箱子掉下边缘。
- **风扇**：纸球只在格栅上方等到被托起为止。

## 机关

- **立在铰链上的木板**（吊桥，P_Modul_25）：短距离助跑撞倒，撞后立即刹车，以免球跟着木板掉进缺口。
- **推杆**（P_Modul_01）：要撞它的圆盘才会移动，靠着推不动；一次不够就撞几次。
- **把松散的球当作钥匙**：需要让松散的球滚到某处触发机关（推杆的圆盘、活板门）时，沿它所在的行斜着撞过去，球随即刹车（第 11 关：把两个石球从格栅上撞到下面的轨道上）。
- **跷跷板**（P_Modul_30）从低的一端助跑通过：石球从静止出发过不了支点。
- **提示在变换器放开球之后才开始**，而不是在它还托着球时：提示结束后会重新找到路线上的位置，而在提示进行中经过的变换器不会被算作已经过。
- **已经过的区段不复存在**：它的物体离开物理和画面，路线不会再回到那里。
- **带笼子的升降台**（P_Modul_03）：弹簧上的圆盘，被松散立在上面的笼壁压住。从中间逐一撞掉笼壁（短促撞击并刹车，让球留在圆盘上）；圆盘升到下一个圆盘的高度，球借推力滚过去（第 12 关）。
- **风扇阶梯**：每个风扇的气柱很窄（宽 2），把纸球托在顶端（格栅上方 17）。球从那里借推力移到低于此高度的下一个格栅；太慢就会从气柱之间掉下去。球必须高于下一个格栅到达其上方：若某气柱顶端只与下一个格栅齐平，球先经过一个更高的气柱（第 12 关第 6 区）。
- **平台上轨道尽头的立柱**彼此间距比球的直径还小：球绕过它们，而不是从中间穿过。
- **在远处下方另一条轨道上空结束的轨道**：从尽头慢慢滚下，球会正好落到下面那条轨道上。

## 球

- **纸球**：越过风扇、沿着气墙；很轻：上坡和下垂的板需要助跑。
- **木球**：用于轨道和大多数靶子；重量足以在高速撞击并继续推时推倒靶子。
- **石球**：用来撞箱子、推球；它会压断悬挂的板（P_Modul_29）：不从上面通过，除非关卡就是要它随板一起落下（第 6 关的塔）。

## 观看者标记的区域

当所有者看到测试玩家开得不对时,他在观看时(`--watch`,F8 和 F4;[autopilot.md](autopilot.md),“区域”)标记这一段,
从此这个标记就是这一段的规则,保存在提示旁的 `<level>.zones` 中:

- **flow**(“这里别拖延”):不做球不需要的停顿、等待或减速。提示的 `goto` 直接穿过,`wait` 和 `hold` 省略,慢速的
  `pass` 或 `press` 以 5 进行,每项仅当运行副本显示球能保住时才这样做;转向至少保持地面节奏的 0.8,但在需要助跑的缺口或坡前除外(为助跑而后退和停下不算磨蹭,那里 flow 区域不提任何要求)。
- **careful**(“限速、不切弯”):不快于区域的速度(默认 4.5),沿路线中线,不走赛车线;无论由什么驾驶都保持在限速以下。
  **物理上需要动量的地方绝不限速**:在要跨越的缺口或比球靠自身推力能爬的更陡的坡之前(限速 4.5 时石球 12.6°,木球 26°,纸球 31°;单靠推力石球爬不上比 17° 更陡的坡,
  木球 37°,纸球 46°;
  路线向前读约 30 单位)、在门槛处,以及正在运行的提示要求速度的地方(比限速快的 `press`、`along` 或 `round`,
  或作为其助跑、比限速快的 `pass`),限速被放开,只保持线路。想在那里拖住球的标记只会让球掉下去。

观看者的区域优先于上面的节奏规则:那是所有者亲眼所见。

## 学习表:`hints/learned.txt`

区域还会告诉测试玩家那是什么样的地方,适用于所有关卡,包括尚未通过的(12、13、我们自己的关卡)。每次标记时,它沿标记段
每十分之一秒按八个特征读取地点:

| 特征 | 取值 |
|---|---|
| surface | `floor`、`rail`、`off`(不在路线的地面上:模块部件、空中) |
| width | 地面宽度:`narrow`(小于 4)、`medium`(小于 10)、`wide` |
| border | 8 以内最近的地面边缘:`walls`(有墙)、`open`(下面是落差)、`far` |
| curve | 路线在接下来 8 个点上的转角:`straight`(小于 20°)、`bend`(小于 60°)、`sharp` |
| slope | 其上的坡度:`flat`、`up`、`down`(超过 0.15) |
| ahead | 其中遇到的第一个:`gap`、`drop`、`rail-end`、`rail-start`、`sill`、`transformer` 或 `none` |
| module | 8 以内最近的模块(`P_Modul_25`、`P_Box` 等)或 `none` |
| kind | `wood`、`stone`、`paper` |

在该段大部分(60%)相同的东西成为一条规则:表面、球,以及该地点特有的值(不是普通的中等或宽地面、直、平、前方无物、无模块);
普通的值被省略,它们只会让规则适用的地方更少。没有特别之处的段落不会学到任何东西(其区域仍只属于本关)。规则追加到提示旁的
`learned.txt`(所有关卡共用一个文件),并记录在哪里学到的以及测试玩家当时在做什么:

```
flow when surface=rail ahead=rail-end kind=wood   # Level_01 sector 2 (147.2 -2.1 -552.0) 2026-11-03: 3.0 s, stopping 40%, mostly hint, off the middle 0.0
careful speed 4.5 when surface=floor width=narrow curve=sharp kind=stone
```

规则在其列出的每个特征都取该值的地方生效;它的要求与同类区域相同(flow、careful)。每次运行都会读取此表并每个 tick 检查地点:
在球不处于本关自己的区域(优先)且有规则生效时,只要其中有 flow 即为 flow,careful 取最低限速;状态行显示生效的最具体规则
(`learned: rail, rail-end ahead, wood → don't dawdle`),按 F12 时还显示规则眼中的地点(`here: surface=rail ...`)。
一条规则至少列出两个特征,其中一个是该地点特有的,这样就不会有规则几乎处处生效;careful 规则要列出两个特有的特征,
因为它在生效的每个地方都会拖住球(单是一个急弯就是每个关卡的每个急弯;复活点旁的一个弯不是每个弯)。只有一个特有
特征的路段上的 careful 标记不会产生规则(其区域仍只属于该关卡),表中这样的行会被跳过并附说明。撤销标记(Backspace)也会删除它学到的规则(按其说明中的标记 id)。表中已有的规则不会重复添加;表已满(512 条规则)时不再接受,屏幕会提示。
此表是纯文本:过宽的规则可通过增加特征来收窄,或直接删除。它与提示文件一样按不受信任的输入读取:大小(64 KiB)、规则数(512)
和数字都有上限,取值只能来自上面的列表,格式错误的行会被省略并注明。`AUTOPILOT_SITUATION=1` 在运行中每秒打印规则眼中的地点。

这些特征在不计模块时区分 2079 种地点(地面 1701、轨道 189、其他 189),每种还可与附近的每个模块组合。

## 关卡的路线：`hints/Level_NN.route`

每个关卡一个文件，供人和代理阅读（测试玩家读取由它做成的计划和提示）：每个小节按顺序列出各段，每段写明用哪种球、按顺序经过的对象、在每个对象处做什么以及节奏。

```
sector 1 wood                         # 小节及其开始时的球
  start → end platform x 166          pass, cruise
  rails x 122 south → Paper_01        pass into it → paper
  Modul_18_01 (fan)                   wait over the grate → lifted onto the rails x 80
  rails x 80 south → Wood_01          press at a push (a slope) → wood
  rails x 80 north, U over the fan    pass, cruise (a wood ball is not lifted)
  rails x 96 south → CP1              press, cruise; on over the sill onto the platform
```

动作：**pass**（按节奏经过）、**press**（沿轨道或直线，保持在线上）、**round**（螺旋）、**hold**（静止、对准）、**cross**（秋千，在找到的时机）、**ram**（箱子，助跑，刹车）、**target**（hold，然后 press 和 push 撞入靶盘）、**wait**（只在风扇格栅上方或为活动部件等待）。
