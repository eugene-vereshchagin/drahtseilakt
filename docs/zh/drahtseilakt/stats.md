# 数字

Drahtseilakt 是如何做出来的，统计于 2026-11-03（`scripts/stats.py`）。每一行代码、这份文档的每一页以及每一个生成的
音效，都由 Claude（Anthropic 的 AI 模型，在 Claude Code 中）编写。主持项目的 Veresk 没有写其中任何一行：他设定目标、
做出决定、试玩、聆听，并指出哪里不对。

## 文档

四种语言（英语、俄语、德语、简体中文），每种 11 页，约 1,200 行。

## 声音

生成的音效主题完全由代码制作：51 个音效和音乐片段——每种球在每种表面上的声音、风扇、雷声、氛围音、十五段弹拨弦乐短句
以及终点音乐——根据原版声音的测量数据合成，没有使用原版的任何一个采样。
