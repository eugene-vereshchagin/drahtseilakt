# Тестовый игрок и его подсказки

`--autopilot` даёт пройти уровень тестовому игроку без окна: он находит путь по полам и трансформерам уровня и
ведёт по нему шар, пробуя каждый выбор стрелок на копии прохождения. `--follow FILE` заставляет его ехать путём
шара из реплея игрока. Некоторые места он сам не проходит: головоломки, рычаги и толкатели, которые надо сначала
ударить, восходящие потоки, рельсы, по которым надо ехать на скорости. Для них он читает **подсказки**.

## Следование за записью игрока

С `--follow REPLAY` тестовый игрок знает запись игрока потиково: где был шар, с какой скоростью, какой шар, в
каком секторе и какие клавиши нажаты. Где его шар там же, где был шар игрока (в пределах 2 единиц, скорость в
пределах 4, тот же шар, тот же сектор, не теряется), клавиши игрока — ещё один вариант на каждом решении (в виде
игрока — те же самые клавиши, включая повороты камеры; в другом виде — те же толчки его стрелками). Он оценивается
на копии забега, как и остальные, и берётся всегда, если не теряет шар: игрок знал то, чего не знает поиск пути
(сначала задеть рычаг, вернуться к трансформеру, подождать на подъёмнике), а собственный короткий путь уводит с
линии игрока насовсем. Где линии игрока рядом нет (игрок там упал или шар ушёл в сторону), рулит поиск пути, а
застряв, он пробует и более длинные отрезки клавиш игрока из ближних мест. Сначала ищется тот тик игрока, до
которого запись дошла с последнего совпадения, чтобы место, где игрок стоял, не проигрывалось снова и снова.
Последние четыре секунды игрока перед потерей шара не повторяются, а после подсказки линия игрока ждёт десять
секунд (подсказка знает место лучше). Застряв там, где ни один манёвр не продвигает, в пределах 30 единиц от
линии игрока, он откатывается к месту раньше, где игрок стоял, и даёт клавиши игрока оттуда (разгон, провал на
скорости), если на копии забега это не теряет шар и продвигает. `AUTOPILOT_DEMO=1` печатает каждое совпадение.

`--then REPLAY` (до 8 раз) присоединяет запись, начатую с сектора (реплей, начинающийся с `start N`): с этого
сектора путь, его трансформаторы и тики игрока берутся из неё. Так уровень проходится с начала по всей записи
владельца и более поздней, которая прошла сектор, не пройденный во всей записи.

## Отчёты о застревании

Если тестовый игрок 20 секунд не продвигается по пути, он пишет отчёт в `--report DIR` (по умолчанию
`stuck/` в папке данных игры), новая папка на каждое место:

- `report.txt`: уровень, тик, сектор, жизни, вид шара, место, скорость и четверть обзора, путь впереди,
  трансформеры, свободные тела и объекты уровня рядом (с их группами);
- `view.png`: что видит игрок; `top.png` и `wide.png`: место сверху, близко и широко.

По отчёту, реплеям владельца (с `AUTOPILOT_TRACE_FOLLOW=1` печатается место шара в реплее каждые полсекунды) и
видео прохождений пишется подсказка.

## Файлы подсказок

Один файл на уровень: `hints/<уровень>.txt` в папке данных игры (`hints/Level_01.txt` для уровня 1) или файл,
указанный в `--hints FILE`. Написанные подсказки лежат в репозитории в `hints/` вместе с реплеями, которые они
используют; данных игры в них нет. Подсказка — строка, `#` начинает комментарий:

```
at X Y Z r R [sector N] [kind wood|stone|paper] : ШАГ ; ШАГ ; ...
```

Когда шар оказывается в пределах R от точки (в этом секторе, этим шаром), шаги выполняются по порядку, раз за
жизнь; потом тестовый игрок снова находит своё место на пути (за трансформаторами, если подсказка превратила шар). Шаги:

| Шаг | Что делает |
|---|---|
| `goto X Y Z [T]` | доехать до точки и остановиться (не дольше T тиков, 600) |
| `via X Y Z [T]` | проехать через точку не останавливаясь; если 1,5 с не приближается — отъезжает и разгоняется |
| `push DX DZ T` | толкать в мировом направлении (DX, DZ) T тиков |
| `air DX DZ T` | толкать по (DX, DZ), пока шар не взлетит и не приземлится (не дольше T) |
| `wait T` | T тиков без стрелок |
| `turn N` | повернуть обзор на N четвертей (отрицательное — влево) |
| `become KIND` | заехать в ближайший трансформер этого вида (не дольше 1200 тиков) |
| `replay FILE FROM TO` | нажатия игрока в тиках FROM..TO из реплея FILE (рядом с файлом подсказок), повёрнутые к обзору тестового игрока; начатый, когда шар держит трансформатор, идёт с момента, когда шар отпущен (FROM: тик превращения у игрока + 149), в такт с игроком |

Направления мировые (X на восток, Z на север, как построен уровень), поэтому подсказка не зависит от поворота
обзора; стрелки подбираются под обзор на каждом тике. Файл подсказок недоверенный: размер (64 КиБ), число
подсказок (256) и шагов (64 на подсказку) и каждое число ограничены, реплей — простое имя файла рядом, испорченная
строка отвергает весь файл с номером строки. `HINTS_TRACE=1` печатает шар каждые десять тиков, пока ведёт
подсказка.
