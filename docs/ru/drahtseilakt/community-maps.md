## Формат каталога

Одна Markdown-таблица, строка на карту, от старых к новым:

| Колонка | Содержимое |
|---|---|
| Posted | дата выхода `ГГГГ-ММ-ДД`; в скобках — приблизительная, `(~…)` — оценка |
| Baidu Tieba ID & Chinese Ballance Forum ID | ID постов; ID форума вида `C126`; может быть пусто или `N/A` |
| Original Name | обычно по-китайски |
| English Name | перевод |
| Author | автор |
| Difficulty | 1–5, иногда половинки (`2.5`) или диапазоны (`2.5–3`) |
| Type | Comprehensive, Technical, Logical, Casual, Skillogic, Racing, Puzzle, Landscape |
| Videos | ссылки на YouTube, несколько через `<br />`; может быть пусто |

Разбирать осторожно: в нескольких строках внутри названия есть `|`, и колонки съезжают (в срезе 25.09.2026
у нескольких строк на месте сложности стоит автор или название). Каждую строку проверять, а битые
выводить в отчёт, а не угадывать.

## Коллекция в цифрах (25.09.2026)

- Около 427 карт, с 2009 по 2026 год; 20–60 новых карт в год.
- Сложность: примерно 75 на 1, 75 на 2, 100 на 3, 100 на 4, 65 на 5.
- Типы: около половины Comprehensive; дальше Technical (~85), Logical (~55), Casual (~30), Skillogic, Racing,
  Puzzle, Landscape.
- Видео: у 366 карт есть хотя бы одно, **у 99 — два и больше**. Карты, которые проходили и выкладывали несколько
  человек, — естественный «топ-100», первая подборка для тестов.

## Соглашения комьюнити по установке карт

- **Подмена уровня**: скопировать карту поверх одного из `3D Entities/Level/Level_01.NMO` … `Level_13.NMO`.
  Моды не нужны.
- **BML**: положить карты в `ModLoader/Maps`; BallanceModLoader(Plus) добавляет меню карт.
- Наш движок не использует ни то, ни другое: карты лежат в его собственной папке и никогда не записываются
  в файлы игры (фаза 4).

Как делают карты: Blender 3.6 с [BallanceBlenderHelper](https://github.com/yyc12345/BallanceBlenderHelper),
экспорт через Virtools 3.5; старые карты — через плагины 3ds Max.

## Локальные копии на машине владельца

Владелец скачал карты и моды. Они лежат **вне репозитория**, как и данные игры, и находятся через переменные
окружения:

| Переменная | Указывает на | Кто использует |
|---|---|---|
| `OPENBALLANCE_DATA` | игру: установленную папку, папку CD или образ диска | тесты на данных игры, сама игра |
| `OPENBALLANCE_MAPS` | папку любительских карт (`.nmo` как скачаны, архивы распакованы) | тесты карт, отчёт о недостающих Building Blocks |
| `OPENBALLANCE_MODS` | папку скачанных модов | только чтение, см. ниже |

Распаковка скачанного — часть работы и идёт по правилам для архивов (`modules/input.md`): каждый путь внутри
архива проверяется (никаких `..`, абсолютных путей и ссылок), с лимитами на число файлов и распакованный
размер. Собственная папка карт движка для игроков (фаза 4) — отдельно от этого рабочего набора.

**Карты** — это данные. Именно их загружает фаза 4 и по ним гоняются тесты: прогон без окна по всей папке,
который загружает каждую карту, какое-то время её играет и сообщает о падениях и недостающих Building Blocks.

**Моды — это код.** Моды BML — это DLL под Windows, которые оригинальный плеер загружает в свой процесс. Они
никогда не исполняются — ни движком, ни тестом, ни «просто посмотреть» под Wine на машине владельца. Польза от
них одна — как источник требований: то, что комьюнити добавило в игру (спидометры, меню карт, настройки камеры,
исправления), говорит, какие возможности нужны игрокам. Такая возможность реализуется в нашем движке заново по
её наблюдаемому поведению, как и любая другая; из мода ничего не загружается.

## Правила для этого проекта

- **Карты — недоверенный ввод**: файлы с чужих дисков. Они проходят только через укреплённые парсеры,
  прошедшие фаззинг (см. `CLAUDE.md`).
- **Файлы карт никогда не попадают в репозиторий** — это работа их авторов, и распространять её под GPL
  мы не вправе. Подборка хранится только как данные: название, автор, дата, строка каталога, ссылка.
- Как карта должна выглядеть и проходиться, берётся из видео в каталоге, а не из того, что показывает наш движок.
