# Как распространяется Drahtseilakt и где что искать

Одна страница на два вопроса: *что мне скачать?* и *где в репозиториях что лежит?* Шаги сборки и выгрузки — в
[release.md](release.md); причины — в [decisions.md](decisions.md), ссылки ниже.

## Что в какой загрузке и почему

Drahtseilakt состоит из трёх частей, которые меняются с разной скоростью, поэтому поставляются раздельно:

- **Программа** (игра, а в портативных архивах и установщиках ещё и toolbox): меняется с каждой версией.
- **Базовые данные**: наши детали, текстуры, шрифты, звуки, фабричные моды, демонстрационный уровень `00-Showcase`,
  скрытый `Parts_Test` и 13 любительских карт `.nmo`. Лежат в git, меняются время от времени.
- **13 выбранных карт** (набор Drahtseilakt): меняются редко. Каждая — отдельный `.zip`, плюс один пакет для Linux,
  `drahtseilakt-levels`.

Почему так:

- **Ограничения GitHub.** Файл в git не может быть больше 100 МБ, ресурс релиза — больше 2 ГиБ. `level.bin` выбранной
  карты больше 100 МБ, поэтому эти карты — только ресурсы релиза (около 1,1 ГБ вместе, каждый файл в пределах лимита);
  базовые данные (около 100 МБ, ни один файл не больше 3,6 МБ) в git помещаются
  ([Бинарники в git: базовые данные](decisions.md#бинарники-в-git-базовые-данные)).
- **Обновления программы остаются маленькими.** Уровни не меняются вместе с программой, поэтому новая версия
  пересобирает только бинарные пакеты, и игроку не нужно заново качать гигабайт. Версия программы — тег `X.Y.Z`; у данных
  своя, `scripts/DATA_VERSION` (дата), а пакеты программы требуют `drahtseilakt-data >= DATA_VERSION`.
- **Своё по умолчанию; ничего из оригинала не распространяется.** В загрузках только то, что сделали мы или что
  разрешили включить авторы (указаны в `CREDITS.md`, `THIRD-PARTY.md`). Ресурсы оригинала делаются на машине игрока из
  его собственной копии (решение «Своё по умолчанию, оригинальное — по желанию игрока» в decisions.md). Это и правовая
  осторожность, и политика проекта в отношении контента.
- **Уровни готовит toolbox, игра только играет.** Импорт копии, ремастеринг, конвертация скачанных карт и апскейлер
  Real-ESRGAN — дело toolbox, отдельной программы в собственном репозитории; игра играет то, что лежит в её папках
  ([Уровни готовит toolbox, игра только играет](decisions.md#уровни-готовит-toolbox-игра-только-играет)). Поэтому
  портативные архивы и установщики содержат обе программы, а пакеты Linux — только игру.
- **Игра никогда не выходит в сеть.** Она не скачивает уровни, обновления и шрифты и не проверяет наличие новой
  версии; файлы с GitHub вы скачиваете сами ([Игра никогда не выходит в сеть](decisions.md#игра-никогда-не-выходит-в-сеть)).
  Скачивать может только сборка — с фиксированными версиями и проверкой контрольных сумм.
- **Портативная или установленная.** Портативная копия (файл `portable.txt` рядом с программой) хранит всё в своей
  папке и ничего больше не трогает; установленная держит данные игрока в его профиле, поэтому удаление программы их не
  стирает ([files.md](files.md)).
- **Dev-сборка** — для разработки, не для игроков: отладочная сборка с включённым god mode (`drahtseilakt-dev`, `-dev` в
  имени). Собирается только по запросу (параметр workflow `dev`) и никогда не входит в релиз.

Единственный уровень, привязанный к игре в коде, — демонстрационный `00-Showcase`; остальные уровни — данные в папках
([levels.md](levels.md)).

## Я хочу X: скачать Y

Самый свежий релиз находят через GitHub API, а не по фиксированной ссылке: `GET https://api.github.com/repos/eugene-vereshchagin/drahtseilakt/releases/latest`, затем в `assets[]` берут файл, чьё `name` подходит под шаблон, например `drahtseilakt-*-windows-x86_64-setup.exe`, и используют его `browser_download_url`. Страница <https://github.com/eugene-vereshchagin/drahtseilakt/releases/latest> всегда показывает самый свежий релиз. В именах файлов версия остаётся (ниже `<version>`; `<data-version>` у пакетов данных), чтобы её было видно. Сверяйте загрузку с `SHA256SUMS` из того же релиза.

| Я хочу | Скачать |
|---|---|
| Играть в Windows с установкой (для одного пользователя, без прав администратора, `%LOCALAPPDATA%\Programs\Drahtseilakt`) | `drahtseilakt-<version>-windows-x86_64-setup.exe` (ARM: `-aarch64-`) |
| Играть в Windows без установки | `drahtseilakt-<version>-windows-x86_64.zip` (ARM: `-aarch64`) |
| Играть в Linux без установки | `drahtseilakt-<version>-linux-x86_64.tar.gz` (ARM: `-aarch64`) |
| Пакеты Debian / Ubuntu | `drahtseilakt_<version>-1_amd64.deb` + `drahtseilakt-data_<data-version>-1_all.deb` (ARM: `drahtseilakt_<version>-1_arm64.deb`) |
| Пакеты Fedora / openSUSE | `drahtseilakt-<version>-1.x86_64.rpm` + `drahtseilakt-data-<data-version>-1.noarch.rpm` (ARM: `drahtseilakt-<version>-1.aarch64.rpm`) |
| Играть в macOS | `drahtseilakt-<version>-macos-aarch64.dmg` (Apple silicon) или `drahtseilakt-<version>-macos-x86_64.dmg` (Intel); без подписи: при первом запуске — правый клик, «Открыть». `.tar.gz` с теми же именами — портативный вариант |
| FreeBSD (экспериментально) | `drahtseilakt-<version>-freebsd-x86_64.tar.gz` |
| Toolbox | внутри каждого портативного архива и установщика; или его собственные релизы: [drahtseilakt-toolbox](https://github.com/eugene-vereshchagin/drahtseilakt-toolbox/releases) |
| 13 выбранных карт | релиз данных `data-<DATA_VERSION>`: по одному `.zip` на карту (распаковать в `assets/levels/drahtseilakt/`), а в Linux — `drahtseilakt-levels` (`.deb`/`.rpm`) |
| Оригинальные уровни Ballance | у нас не скачать: toolbox импортирует их из вашей собственной копии |
| Попробовать самый свежий невыпущенный код | собрать самому ([README](https://github.com/eugene-vereshchagin/drahtseilakt/blob/main/README.ru.md)) или взять артефакты запуска workflow (сборки `git-<sha>`, пакеты `0~git<sha>`) |

Портативные архивы и установщики содержат базовые данные, поэтому играть можно сразу; пакетам Linux нужен пакет с данными
рядом с программой (`apt install ./drahtseilakt-data_*_all.deb ./drahtseilakt_*_amd64.deb`). Точный список файлов релиза и строки
установки — в [release.md](release.md).

## Где что лежит

| Где | Что |
|---|---|
| `eugene-vereshchagin/drahtseilakt` (этот репозиторий) | игра, крейты движка (`crates/`: `nmo`, `level`, `gamedata`, физика `ivp`, `script`, `game`, ...), `assets/` (базовые данные), `docs/`, `scripts/`, `tools/`, `hints/` (планы автопилота), `tests/` |
| `eugene-vereshchagin/drahtseilakt-toolbox` | toolbox, со своими релизами и CI; читает уровни через `crates/gamedata` и `crates/level` этого репозитория |
| `assets/` | то, что поставляется с игрой: наши детали, шрифты, звуки, фабричные моды, `levels/community/` и `levels/drahtseilakt/` (там только `level.txt` выбранных карт; их файлы — ресурсы релиза) |
| `docs/drahtseilakt/` | документация проекта (дорожная карта, решения, форматы, меню, моды); каждая страница есть и в `docs/ru/`, `docs/de/`, `docs/zh/` |
| `docs/manual/<язык>/` | руководство игрока; `tools/make_manual.py` собирает его в `assets/manual`, которого нет в git: его делает CI (`scripts/ci-assets.sh`), а игра открывает его по F1 |
| `scripts/` | упаковка релиза (`ci-package.sh`, `make-distro-packages.sh`, `pack-assets.sh`, `DATA_VERSION`) |
| `.github/workflows/` | CI: тесты (`drahtseilakt.yml`) и релиз (`drahtseilakt-release.yml`); оба запускаются по требованию |
| `docs/internals/`, `docs/*.md` в корне | заметки и справочники по обратной разработке из upstream OpenBallance, оставлены как справочный материал |

## Правила для контрибьюторов

- **Никаких оригинальных ресурсов**: ни файла, ни текстуры, звука или модели Ballance в git, пакете, тесте или
  фикстуре. Тесты, которым нужна игра, читают её из `OPENBALLANCE_DATA`; ничто из загрузок не взято из оригинала.
- **Зафиксированные зависимости**: крейты в `Cargo.lock` (vendored, сборка работает офлайн), actions — по полному SHA
  коммита, инструменты и скачиваемые бинарники — по версии и SHA-256. Зависимость добавляют, только проверив, что она
  существует, поддерживается и имеет лицензию, совместимую с GPL-3.0 (следят `tools/third_party.py` и тест).
- **Четыре языка**: изменение документации идёт на английском, русском, немецком и китайском (упрощённом) в одном
  коммите; новая страница получает пункт боковой панели в каждой локали (`docs/.vitepress/config.ts`). Тексты меню
  должны помещаться на всех языках.
- **CI запускается по требованию** и на pull request, а не на каждый push: собирайте изменения в пачки.
- **Игра не ходит в сеть**; скачивать может только сборка.
- **Релизы — только владелец**: никто не ставит тег, не публикует и не выгружает релиз данных без его прямой команды.
  Тег `X.Y.Z` создаёт черновик; публикует его он.

Подробности — в `CLAUDE.md` в корне репозитория.
