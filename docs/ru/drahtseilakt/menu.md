# Меню: схема оригинала и наша

План меню игры, согласованный с владельцем 2026-11-02. Пока игрок не включил расширенный режим, игра как можно
точнее повторяет оригинал; единственное видимое отличие — ещё одна опция, которая включает расширенный режим.
У расширенного режима свои настройки: что показывать, какие наши дополнения включать, любительские карты.

## Меню оригинала

Прочитано из `3D Entities/Menu.nmo` копии (скрипты `Menu_*`) и `Language.nmo` (строки на немецком, английском,
испанском, итальянском и французском; столбец выбирает `GameSettings.Language`), проверено в игре на C.

| Экран | Строки сверху вниз | Примечания |
|---|---|---|
| Главное (`Menu_Main`) | Start, Highscore, Options, Credits, Exit | Exit спрашивает «Do you want to quit the game?» (Yes / No) |
| Start (`Menu_Start`) | Level 1 … Level 12, Back | уровень открывается, когда пройден предыдущий (`DB_Levelfreischaltung`); остальные серые. Дополнение с 13-м уровнем заменяет Menu.nmo и добавляет свою строку |
| Highscore (`Menu_Highscore`) | «Highscore Level N», десять имён с очками, Back; влево и вправо меняют уровень | начальные таблицы копии — массивы `DB_Highscore_LvNN` в base.cmo («Mr. Default») |
| Options (`Menu_Options`) | Graphics, Controls, Sound, Back | |
| Graphics (`Menu_Opt_Graphics`) | Screen Resolution, Synch to Screen? (Yes/No), Clouds? (Yes/No), OK | |
| Controls (`Menu_Opt_Keys`) | Forward, Backward, Left, Right, Rotation, Overview — по клавише; Invert Rotation? (Yes/No); OK | по умолчанию стрелки, Shift, пробел |
| Sound (`Menu_Opt_Sound`) | Music Volume, OK | одна громкость |
| Credits (`Menu_Credits`) | титры оригинала | |
| Пауза, Esc на уровне (`Menu_Pause`) | Back, Restart Level, Highscore, Options, Exit Level | Restart и Exit сначала спрашивают Yes / No; очки остаются на экране |
| Смерть, жизней нет (`Menu_Dead`) | Restart Level, Home | |
| Очки на финише (`Menu_Score`) | Level Bonus, Time Points, Extra Lives, Score | считаются строка за строкой |
| Новый рекорд (`Menu_HighscoreEntry`) | «New highscore entry!», очки, ввод имени, OK | предлагается последнее введённое имя (`DB_Options.LastPlayer`) |
| Конец уровня (`Menu_End`) | Next level, Restart Level, Highscore, Options, Home | |

Настройки и рекорды хранятся в `Database.tdb` в папке игры. Профилей игроков нет: единственное «личное» — имя в
таблице рекордов.

## Наш классический режим (по умолчанию)

- Те же экраны, строки, порядок и тексты, что в таблице, нарисованные текстурами и шрифтами копии. Строки берутся
  из `Language.nmo` копии, так что меню говорит на языке копии.
- **Одно дополнение**: в Options четвёртая кнопка — *Extended*; на её странице переключатель *Extended mode?*
  (Yes / No). Это единственное отличие, которое видит игрок оригинальных уровней.
- Уровни открываются как в оригинале. Рекорды — как в оригинале: десять на уровень, очки, имя. Начинаются с
  таблиц копии и сохраняются в нашей папке данных, никогда не в файлах игры. Прочитать `Database.tdb` игрока, чтобы
  перенести его старые рекорды, — возможность на потом (это разборщик файла, ревью как у любого).
- Настройки оригинала, которых у нас пока нет (разрешение, синхронизация, облака, клавиши), добавляются по мере
  того, как сделано их поведение; до тех пор их строки показывают текущее значение и не меняются.
- Каждый пройденный забег по-прежнему сохраняется как реплей (на экране это ничего не меняет); самый быстрый —
  лучшее время, которое показывает расширенный режим.

## Наш расширенный режим

Включается в Options или на один запуск через `--debug`. Меню сохраняют вид оригинала; меняется вот что:

- **Главное меню**: Start, *Custom levels*, Highscore, Options, Credits, Exit.
- **Options**: на странице *Extended* переключатель режима и под ним по переключателю на каждое его
  дополнение (с режимом все включены; выключенные настройки хранят как `extended.<ключ> off`):
  - все уровни открыты, без прохождения предыдущих;
  - лучшие времена рядом с уровнями;
  - строка Custom levels в главном меню;
  - инструменты тренировки: свободная камера (F2), медленнее и быстрее (`[` `]`), сохранить момент и вернуться к
    нему (F5 / F9), сектор и тик на экране; забег с такой помощью сохраняется, но лучшим не становится;
  - громкость звуков рядом с громкостью музыки.
  Новые переключатели появятся вместе с функциями из плана (угол обзора, таймеры, призрак лучшего забега).
- **Custom levels**: каждая любительская карта и уровень в открытом формате из `levels/` ([levels.md](levels.md)) —
  строка с именем файла, играется как оригинальный уровень. Карта, которую не
  удалось загрузить, говорит почему и не запускается. Её забеги и лучшие времена хранятся отдельно от
  оригинальных уровней. Позже: название, автор и сложность из каталога сообщества, подпапки как наборы.
- Сюда же — паки текстур и наши моды, когда они появятся, каждый за своим переключателем и с предупреждением, что
  сторонний контент игрок запускает на свой риск.

## Профили

В оригинале их нет (см. выше). У нас профиль объединял бы имя, настройки, открытые уровни, рекорды и реплеи,
чтобы за одним компьютером могли играть несколько человек. Классическому режиму он не нужен: там, как в
оригинале, одно имя при записи рекорда. Открытый вопрос владельцу: делать ли профили позже как возможность
расширенного режима.
