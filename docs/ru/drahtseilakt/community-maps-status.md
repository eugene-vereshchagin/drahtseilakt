# Любительские карты: где они сейчас

Обзор 579 любительских карт в `levels/community/` владельца (2026-11-02; карты из
[CustomMapList](community-maps.md): Custom Maps 408, Pro Racing 97, Reverse Maps 35, 45-Degree Rotated Maps 13,
Invisible Maps 13, Original Maps 13). Каждая загружена и сыграна 300 тиков без окна, выгружена в открытый формат и
загружена снова, а её скрипты Virtools перечислены (блоки по имени). Это план для интерпретатора скриптов и модов;
**2026-11-09:** первая фаза интерпретатора сделана ([scripts.md](scripts.md)): ядро, блоки шаблона и самые
используемые из остальных; у 173 из 184 карт со скриптами (584 карты вместе с `community-unsorted/`) все блоки известны, 8 из 36 карт с
собственными скриптами идут с полным действием каждого блока.

| | карт |
|---|---|
| загружаются и играются по встроенным правилам игры | 579 |
| имеют стандартные группы (старт, финиш, чекпоинты, точки возрождения) | 579 |
| выгружаются в открытый формат | 579 |
| загружаются снова из открытого формата | 578 |
| несут свои скрипты Virtools | 188 |

**Та, что не загружается снова:** в `Custom Maps/Beautiful.NMO` у одного объекта в матрице не конечное число; игра
играет `.nmo`, но открытый формат отвергает такую матрицу. Сделать: выгрузка пишет такой объект так, как его
использует игра (или пропускает), с предупреждением.

**Скрипты.** Свои графы поведения несут 188 карт, все из Custom Maps, кроме 4 из Reverse Maps. 142 из них несут одни
и те же девять блоков (Activate Script, Binary Switch, Change Texture Video Format, Deactivate Script, Get Cell,
Object Delete, Op, Point Particle System, TT Scaleable Proximity), ещё 7 — их же с Wait Message: скрипты, которые
шаблон картостроителей приносит для частиц огней, а игра рисует их сама. Теряют ли эти карты что-то без них — проверить
игрой; встроенные правила и так проводят каждую карту через старт, чекпоинты и финиш. Остальные 39 карт используют
свои скрипты: всего 107 блоков, большинство — в одной-двух картах.

**Блоки по числу карт** (порядок для интерпретатора): Op 184, Get Cell 183, Object Delete 183, Activate Script 182, Binary Switch 182, Deactivate Script 182, Point Particle System 182, Change Texture Video Format 180, TT Scaleable Proximity 179, Wait Message 35, Group Iterator 22, Hide 20, Physicalize 19, Box Box Intersection 19, Set Position 18, Iterator 17, Show 16, Switch On Parameter 16, Add Row 15, Delayer 15, PlanarParticleSystem 14, Get Key Row 13, Object Copy 13, Send Message To Group 12, Test 11, Text Display 11, Set Cell 9, Wave Player 9, Nop 8, Restore IC 8; дальше 77 блоков, каждый
меньше чем в 8 картах (среди них физические силы и импульсы, текст и шрифт, клавиши и мышь, таймеры и счётчики, свет,
текстуры и звуки).

**Что это значит.** Встроенные правила играют каждую карту; интерпретатор девяти блоков шаблона и следующих двадцати
покрыл бы то, что добавляют карты со скриптами (движущиеся и прячущиеся объекты, изменения физики, копии, сообщения,
текст, звуки). Карта никогда не запускается наполовину: карта, которой нужен нереализованный блок, сообщается с его
именем.

## Аудит: что карта просит и что получает (2026-11-10)

`drahtseilakt --audit FILE|DIR [--audit-csv FILE]` проходит карту, папку уровня открытого формата (с `level.gltf`) или папку таких без окна, с копией игрока и без
неё, и для каждой карты перечисляет: каждое тело, которое физика делает из объекта уровня и которое не рисуется
(невидимое препятствие — с именем, местом и причиной), заглушки, для которых не сделан модуль, модули и текстуры,
которых ни у кого нет, объекты классов, которые загрузчик пропускает, альфа-тесты, которым рендер не следует, и
неизвестные блоки скриптов. В CSV одна строка на карту, копию и вид проблемы с именами; сводка ранжирует виды по
числу затронутых карт. `--show-colliders` рисует скрытые картой полы и рельсы (красным) и скрытые стопоры (жёлтым)
полупрозрачными в игре и на снимках.

Первый прогон по 605 картам (26 поставляемых и 579 из коллекции) нашёл причины «невидимых объектов», и три
правила изменены для всех карт:

| причина | карт | теперь |
|---|---|---|
| заглушка узнавалась по имени (`P_Modul_26_01`) и только как видимый меш без материала; карты из Blender называют её `P_Modul_26_01_.001`, дают ей материалы или прячут, поэтому модуль не делался, а заглушка оставалась невидимым или белым твёрдым телом | 71 + 29 + 22 | член группы модуля — заглушка, как её берёт инициализация уровня в оригинале |
| пол, рельс или стопор без материала сталкивался, но не рисовался | 42 | рисуется однотонным |
| группа, не являющаяся модулем игры (`P_Modul_Portal` мода), делала своих членов твёрдыми | 13 | никогда не тело; рисуется как обычный объект |

Что осталось, по числу карт (с копией): скрытые в файле полы и рельсы, которые сталкиваются, — 204 карты, скрытые
стопоры — 160 (собственные невидимые коллайдеры карт, как в оригинале; их показывает `--show-colliders`); объекты
непрочитанных классов — 58 (2D-объекты 34, кривые 16, звуки 9, патч-меши 2); текстуры без имени файла и без
пикселей — 35; меши с гранями без материала — 30 (рисуются серыми); модули модов — 17; неизвестные блоки скриптов —
11; полностью прозрачные полы — 6.

### Сверено с оригиналом: скрытые коллайдеры и анимации объектов (2026-11-10)

**Скрытые полы и рельсы остаются твёрдыми.** Инициализация уровня в оригинале физикализует каждого члена групп
`Phys_Floors` и `Phys_FloorRails`, а Physicalize не смотрит, показан ли объект (порт блока в эталоне,
`src/bb/bb_physics.c`). На это опираются уровни самого оригинала: в 7 из 12 его файлов уровней там лежат 19
скрытых объектов (`A02_inv_Coll_00`..`04` в уровне 6, `A07_Floor_Invisible_Col` в уровне 11, `A7_invisibleCollCube`
в уровне 12). Правило не менялось. В Go Ahead скрытые стены стоят парами вдоль трассы по обе стороны трансформера
(`Box04` / `Box05`): это коридор, который не даёт объехать трансформер, а не стена поперёк пути; скриптов в карте
нет, так что ничто их не убирает.

**Анимации объектов: их ничто не проигрывает.** В 88 картах лежит 9871 объект анимации (классы 15 и 18). Ни в одной
из 605 карт нет блока, который их проигрывает (Play Animation 3D Entity, Play Global Animation), и нет параметра,
который держит анимацию, а сам Virtools анимаций не проигрывает. 9287 из них — запекание экспортёра: по 35 ключей
позиции, поворота, масштаба и оси масштаба, и каждый ключ равен первому. У 356 своих ключей нет, 8 — руки шара
(balloon) самой игры. В оригинале ничего не движется, поэтому и игра ничего не двигает. Аудит считает их отдельно
(`animation-unplayed`), называет ту, чьи ключи двигали бы объект, и сообщает `animation-played` для карты, в
которой есть чем анимацию проиграть. `nmo-dump --anims FILE...` печатает каждую анимацию с её объектом,
контроллерами и тем, как далеко уходят ключи. То, что в картах сообщества действительно движется, двигают их
скрипты (Set Position, Rotate, Physicalize, Set Physics Slider; около двадцати карт) — это следующая фаза
исполнителя скриптов ([scripts.md](scripts.md)).
