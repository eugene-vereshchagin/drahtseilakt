# Где игра хранит файлы

Игра читает файлы двух видов: **поставляемые ресурсы** (`assets/`: шрифты, свои детали, уровни, фабричные моды, звуковые темы) и **данные игрока** (настройки, повторы, рекорды, привезённые и свои уровни, паки, моды и звуковые темы игрока). Обе раскладки ниже работают с одной и той же программой.

**Поставляемые ресурсы**, берётся первое найденное: `$DRAHTSEILAKT_ASSETS`; `assets/` рядом с программой; `../Resources/assets` (пакет .app на macOS); и только для разработчиков исходное дерево, в котором программа собрана (`assets/` тремя папками выше `target/release` или путь, с которым она скомпилирована). При запуске игра печатает одну строку `paths: assets ... | data ... (portable|per-user)`, её повторяет и журнал сессии.

**Портативная** (скопировал папку и играй; ничего вне неё не трогается): рядом лежат `drahtseilakt(.exe)`, `assets/` и пустой файл `portable.txt`. Данные игрока тогда в `data/` рядом с программой. Правило одно: нет `portable.txt` — нет портативного режима.

**Установленная** (программа и `assets/` в одной папке, например `/opt/drahtseilakt`, `C:\Program Files\Drahtseilakt`, Resources пакета .app): данные игрока в папке пользователя: `$XDG_DATA_HOME/drahtseilakt` (по умолчанию `~/.local/share/drahtseilakt`) в Linux, `%APPDATA%\drahtseilakt` в Windows, `~/Library/Application Support/drahtseilakt` в macOS. Паки, моды и темы игрока оттуда находятся в дополнение к поставляемым.
