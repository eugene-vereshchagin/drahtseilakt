# Где игра хранит файлы

Игра читает файлы двух видов: **поставляемые ресурсы** (`assets/`: шрифты, свои детали, уровни, фабричные моды, звуковые темы) и **данные игрока** (настройки, повторы, рекорды, привезённые и свои уровни, паки, моды и звуковые темы игрока). Обе раскладки ниже работают с одной и той же программой.

**Поставляемые ресурсы**, берётся первое найденное: `$DRAHTSEILAKT_ASSETS`; `assets/` рядом с программой; `../Resources/assets` (пакет .app на macOS); `../share/drahtseilakt/assets` (установка под префиксом: пакеты Linux кладут программу в `/usr/bin`, данные в `/usr/share/drahtseilakt/assets`); и только для разработчиков исходное дерево, в котором программа собрана (`assets/` тремя папками выше `target/release` или путь, с которым она скомпилирована); в самом конце `drahtseilakt/assets` в каждой папке из `$XDG_DATA_DIRS` (по умолчанию `/usr/local/share:/usr/share`). Пакеты релиза: [release.md](release.md). При запуске игра печатает одну строку `paths: assets ... | data ... (portable|per-user)`, её повторяет и журнал сессии.

**Портативная** (скопировал папку и играй; ничего вне неё не трогается): рядом лежат `drahtseilakt(.exe)`, `assets/` и пустой файл `portable.txt`. Данные игрока тогда в `data/` рядом с программой. Правило одно: нет `portable.txt` — нет портативного режима.

**Портативная сборка** (`scripts/make-portable.sh`) делает такую папку с игрой и тулбоксом, по одной на систему: по умолчанию `drahtseilakt-portable/<os>-<arch>/` рядом с рабочей копией (`linux-x86_64`, `windows-x86_64`; `--target linux|windows`, другая папка — аргументом). Скрипт собирает обе программы в release без сети и складывает: игру (`drahtseilakt.exe`; в Linux запускатель `drahtseilakt` и программа `drahtseilakt.bin`, а в `lib/` библиотеки звука, ввода и udev: `libasound`, `libudev`, `libcap`, их лицензии в `lib/LICENSES/`), тулбокс (`drahtseilakt-toolbox(.exe)`; он так же находит `portable.txt`, поэтому всё, что он конвертирует и ремастерит, попадает в этот `data/`), `realesrgan/` (Real-ESRGAN из закреплённой загрузки тулбокса для этой системы, проверенной по SHA-256, с `LICENSES.txt`; в Windows вместе с `vcomp140.dll` из релиза; без него сборка не делается), в Windows DLL MinGW, которые импортируют программы, `assets/` (всё поставляемое, проверенное по `SHA256SUMS`; без `mods-dev/`, `own/make/` и кешей Python), `README.txt`, `LICENSE`, `CREDITS.md`, `THIRD-PARTY.md`, `VERSION` (`git describe` обоих репозиториев), `portable.txt` и пустую `data/`. Это релизная сборка, для любой системы: без модов разработчика. `--dev` (только Linux) делает сборку разработчика в `<os>-<arch>-dev/`: с `assets/mods-dev/` (god-mode), с пометкой DEV в `VERSION` и `README.txt`. Повторный запуск на той же папке заменяет программы и ресурсы и сохраняет `data/`. `--with-originals DIR` импортирует оригинальные уровни из копии Ballance в `data/`, как это делает импорт игры: только для частных тестовых сборок, никогда для публикуемых.

**Установленная** (программа и `assets/` в одной папке, например `/opt/drahtseilakt`, `C:\Program Files\Drahtseilakt`, Resources пакета .app): данные игрока в папке пользователя: `$XDG_DATA_HOME/drahtseilakt` (по умолчанию `~/.local/share/drahtseilakt`) в Linux, `%APPDATA%\drahtseilakt` в Windows, `~/Library/Application Support/drahtseilakt` в macOS. Паки, моды и темы игрока оттуда находятся в дополнение к поставляемым.
