# Уровни и папки

## Что идёт в комплекте

В игру встроены два набора карт, так что играть можно сразу, ничего не добавляя:

- **Избранные карты** — 13 карт авторов из сообщества, выбранных нами, с округлыми формами и улучшенными нами текстурами: это не те текстуры, что изначально взял автор.
- **Карты сообщества, В комплекте** — ещё 13 карт сообщества в тех файлах, в которых их сделали авторы, без текстур оригинала, с указанием авторов.

Все они принадлежат своим авторам и показаны с благодарностью. Если автор попросит убрать карту, мы её уберём.

## Ваша папка данных

Настройки, рекорды, реплеи и ваши уровни игра хранит в одной папке данных:

| Система | Папка данных |
|---|---|
| Linux | `~/.local/share/drahtseilakt/` |
| Windows | `%APPDATA%\drahtseilakt\` |
| macOS | `~/Library/Application Support/drahtseilakt/` |
| Портативная копия | папка `data/` рядом с программой (рядом лежит файл `portable.txt`, и ничего вне папки не используется) |

В ней папка `levels/` содержит такие папки:

| Папка | Что в ней |
|---|---|
| `ballance-original/` | ваша копия оригинальной игры, положенная туда инструментарием |
| `ballance-remaster/` | оригинальные уровни, переделанные в 4K, их делает `drahtseilakt-toolbox` |
| `user-levels/` | ваши и скачанные карты |
| `modified/` | переделки оригинальных уровней от сообщества (повёрнутые, обратные, невидимые); нужна ваша копия |

## Правило: уровень — это папка

Уровень считается уровнем, **только** если он лежит в собственной папке с именем, где есть **один файл `.nmo`**
(или уровень в открытом формате) **и файл описания `level.txt`**. Отдельный `.nmo`, брошенный в папку, или папка без
`level.txt` в списке не показываются.

```
user-levels/
  Моя карта/
    Моя карта.nmo
    level.txt
    preview.png        (картинка, по желанию)
  Сезон 1/             (папка для группировки: своего уровня в ней нет)
    Другая карта/
      Другая карта.nmo
      level.txt
```

Папка без собственного уровня считается группирующей, игра заглядывает внутрь. Не кладите два уровня в одну папку.

### level.txt

Простой текстовый файл со строками `ключ = значение`. Строка, начинающаяся с `#`, — комментарий.

```
# Моя первая карта
title = My Map
title.ru = Моя карта
author = Ваше имя
version = 1.0
difficulty = 4
```

| Ключ | Значение |
|---|---|
| `title` | название в списке (по-английски; показывается не больше 40 символов) |
| `title.ru`, `title.de`, `title.zh` ... | название на другом языке, показывается, когда меню на этом языке |
| `author` | автор карты |
| `version` | версия карты |
| `difficulty` | сложность, целое число от 1 до 10; по нему сортируется список |
| `order` | число, которое ставит уровень в списке раньше |

По-настоящему нужна только строка `title`; файл может занимать до 4 КБ.

### «Некоторые записи в папке уровней неверны»

В списке ваших уровней игра может сообщить, что некоторые записи неверны. Это значит, что она нашла папку или файл,
не подходящие под правило выше: лежащий отдельно `.nmo`, папку без `level.txt` или папку с несколькими уровнями.
Чтобы исправить: положите каждую карту в свою папку, добавьте `level.txt` хотя бы со строкой `title` и откройте список
снова. В журнале игры названа каждая пропущенная запись.

Проще всего справиться с этим через [инструментарий](toolbox.md): его *импорт карт* раскладывает целую скачанную
коллекцию в нужную форму.
