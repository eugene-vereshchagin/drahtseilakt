# Моды

Моды — небольшие дополнения, меняющие поведение игры: таймер, свободная камера, липкий шар. Они описаны простым
текстовым файлом и никогда не запускаются как программы. Моды доступны в **расширенном режиме**.

## Включение модов

1. *Настройки, Расширенный*: включите *Расширенный режим?*.
2. Откройте *Моды*. Влево и вправо включают и выключают выбранный мод, Enter открывает его страницу с параметрами и
   клавишами.

Мод, меняющий правила забега (гравитацию, липкие стены, прыжки между секторами и т. п.), помечает ваш заход как
**с модами**: он сохраняется, но никогда не считается лучшим временем или рекордом. Моды, которые меняют только
картинку или показывают сведения, заход не затрагивают.

## Моды из комплекта

| Мод | Что делает |
|---|---|
| Назад в 2004 | игра как на компьютере 2004 года: низкое разрешение в крупных пикселях, мерцающие дали |
| Затемнение | уровень погружается во тьму; над шаром слабый свет |
| Кривой шар | деревянный шар случайно меняет форму, только на вид |
| Динамический обзор | обзор расширяется с ростом скорости шара |
| Свободное управление | мышь вращает обзор, а стрелки толкают шар по повёрнутому обзору (с модами) |
| Свободный обзор | мышь вращает обзор вокруг шара; клавиша возвращает его |
| Информация на экране | позиция, скорость, оставшиеся бонусы, кадры в секунду, часы |
| Помехи | полупрозрачные шары-обманки кружат вокруг шара |
| Физическая лаборатория | гравитация вниз и вбок и множитель времени физики (с модами) |
| Время игры | считает время, проведённое в каждом уровне и во всех |
| Быстрый перезапуск | клавиша сразу начинает уровень заново |
| Опоры мешков | качающиеся мешки висят на колоннах и мачтах, а не в воздухе (включён по умолчанию) |
| Клавиша скриншота | клавиша сохраняет кадр в PNG в папку `screenshots` внутри папки данных |
| Прыжок по секторам | клавиши начинают уровень заново со следующего или предыдущего сектора (с модами) |
| Таймер по секторам | время забега, реальное время и сплиты секторов против лучшего забега |
| Плавная камера | камера плавно доводит повороты и скользит, как в кино |
| Точка возрождения | клавиша ставит точку там, где шар, другая возвращает шар туда (с модами) |
| Призрак рекорда | ваш лучший забег катится рядом полупрозрачным шаром |
| Липкий шар | прилипает ко всему; толкайте в стену, чтобы залезть по ней (с модами) |

Можно добавить и свои моды: папка с файлом `mod.txt` внутри папки `mods/` в вашей папке данных.
