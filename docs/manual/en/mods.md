# Mods

Mods are small add-ons that change how the game behaves, such as a timer, a free camera or a sticky ball. They are
described in a simple text file and are never run as programs. Mods are available in the **extended mode**.

## Switching mods on

1. *Options, Extended*: turn *Extended mode?* on.
2. Open *Mods*. Left and Right switch the chosen mod on or off; Enter opens its page with its options and keys.

A mod that changes the rules of the run (gravity, sticky walls, jumps between sectors and the like) marks your run as
**modded**: it is kept, but it is never your best time or a highscore. Mods that only change the picture or show
information leave your run as it was.

## The mods that come with the game

| Mod | What it does |
|---|---|
| Back to 2004 | the game as on a PC of 2004: low resolution in hard pixels, shimmering distance |
| Blackout | the level goes dark; a faint light hangs over the ball |
| Deformed ball | the wooden ball wobbles out of shape, only as a picture |
| Dynamic field of view | the view widens with the ball's speed |
| Free steering | the mouse turns the view and the arrows steer along it (modded) |
| Free view | the mouse turns the view around the ball; a key turns it back |
| Info overlay | position, speed, extras left, frames per second and a clock |
| Interference | translucent decoy balls drift around your ball |
| Physics lab | change gravity, also sideways, and the time factor of the physics (modded) |
| Play time | counts the time you play each level and in total |
| Quick restart | a key starts the level again at once |
| Sack supports | the swinging sacks hang on columns and masts instead of thin air (on by default) |
| Screenshot key | a key saves the picture as a PNG in the `screenshots` folder of your data folder |
| Sector jump | keys start the level again at the next or previous sector (modded) |
| Segment timer | run time, real time and sector splits against your best run |
| Smooth camera | the camera eases into its turns and glides like in a film |
| Spawn point | a key sets a spawn point where the ball is, another returns the ball there (modded) |
| Spirit trail | your best run of the level rolls beside you as a translucent ball |
| Sticky ball | holds on to what it touches; push into a wall to climb it (modded) |

You can add mods of your own: a folder with a `mod.txt` inside the `mods/` folder of your data folder.
