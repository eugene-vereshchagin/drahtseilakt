Drahtseilakt (German for "tightrope act") is a new engine for **Ballance**, the 2004 puzzle game in which you roll a ball
along narrow rails and bridges high above an abyss. It does not need the original game to be fun: it comes with a set
of community maps and our own sounds and music (our favourite 13 maps are a separate download, see
[Levels and folders](levels.md)). If you own the original Ballance, it
also plays the original's 13 levels from your own copy.

## Installing

Download the file for your system from the [newest release](https://github.com/eugene-vereshchagin/drahtseilakt/releases/latest):

- **Windows**: the installer `…-windows-x86_64-setup.exe`, or the portable `…-windows-x86_64.zip` (unpack anywhere and start `drahtseilakt.exe`). ARM computers take the `aarch64` files.
- **macOS**: `…-macos-aarch64.dmg` (Apple Silicon) or `…-macos-x86_64.dmg` (Intel). The game is not signed: the first time, right-click it and choose *Open*.
- **Linux**: the portable `…-linux-x86_64.tar.gz` (unpack and start `drahtseilakt`), or the packages. A package install needs two files, the program and its data package `drahtseilakt-data` (our parts, sounds, mods, this manual and the community maps):
  `sudo apt install ./drahtseilakt-data_*_all.deb ./drahtseilakt_*_amd64.deb` (Debian, Ubuntu) or
  `sudo dnf install ./drahtseilakt-data-*.noarch.rpm ./drahtseilakt-*.x86_64.rpm` (Fedora).
  With the 13 featured maps add `./drahtseilakt-levels_*_all.deb` (or `./drahtseilakt-levels-*.noarch.rpm`) from the `data-<date>` release.
- **FreeBSD** (experimental): `…-freebsd-x86_64.tar.gz`.

The installers and portable archives already hold all the data. The 13 featured maps are a separate download ([Levels and folders](levels.md)).

## Where to start

1. Press **Start** in the main menu and choose **Community maps** (or **Featured maps**, if you have downloaded them). Pick a level and roll.
2. Hold **Space** to lift the camera and look at the way ahead; **Shift + Left / Right** turns the camera.
3. Stuck or lost? **Esc** opens the pause menu, where you can restart the level.
4. Want the original Ballance levels or 4K textures? See [The toolbox](toolbox.md).
5. Want to add maps you downloaded? See [Levels and folders](levels.md).
