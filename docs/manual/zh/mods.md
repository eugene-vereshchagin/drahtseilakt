# 模组

模组是改变游戏行为的小型扩展，例如计时器、自由镜头或粘性球。它们由简单的文本文件描述，绝不会作为程序运行。
模组在 **扩展模式** 中可用。

## 开启模组

1. *设置、扩展*：开启 *扩展模式?*。
2. 打开 *模组*。左 / 右键开关所选模组；Enter 打开它的页面，查看选项和按键。

改变游玩规则的模组（重力、粘墙、区段间跳转等）会把您的游玩标记为 **已改动**：它会被保存，但永远不算最佳时间或最高分。
只改变画面或显示信息的模组不会影响您的游玩。

## 自带的模组

| 模组 | 作用 |
|---|---|
| 回到2004年 | 像2004年的电脑一样：低分辨率的大像素，远处闪烁 |
| 黑暗模式 | 关卡变暗，球上方有微弱光源 |
| 变形球 | 木球外形随机变形，只是画面 |
| 动态视野 | 球速越快，视野越宽 |
| 自由操控 | 鼠标旋转视角，方向键沿旋转后的视角推动球（已改动） |
| 自由视角 | 鼠标绕球旋转视角；按键复位 |
| 信息叠加 | 位置、速度、剩余奖励、帧率和时钟 |
| 干扰 | 半透明的诱饵球绕着您的球转 |
| 物理实验室 | 可调向下与侧向重力及物理时间倍率（已改动） |
| 游戏时长 | 统计每关及总的游戏时长 |
| 快速重来 | 一键立即重新开始本关 |
| 沙袋支架 | 摆动的沙袋挂在立柱和桅杆上，不再悬在空中（默认开启） |
| 截图键 | 一键将画面保存为 PNG，存入数据文件夹的 `screenshots` 文件夹 |
| 跳转区段 | 按键从下一区段或上一区段重新开始（已改动） |
| 分段计时器 | 本局用时、真实时间及各区段与最佳成绩的对比 |
| 平滑镜头 | 镜头转动平滑过渡，如电影般滑行 |
| 自设出生点 | 一键在球所在处设出生点，另一键把球送回那里（已改动） |
| 幽灵球 | 本关最佳成绩以半透明球的形式同行 |
| 粘性球 | 会粘住接触的表面；朝墙推即可爬墙（已改动） |

您也可以添加自己的模组：在数据文件夹的 `mods/` 文件夹中放一个带 `mod.txt` 的文件夹。
