# 关卡与文件夹

## 游戏自带什么

游戏自带一套地图，无需任何额外内容即可开玩：

- **社区地图，随附**：13 张社区地图，保持作者制作时的原始文件，不含原版纹理，并标明作者。它们随游戏附带。

另一套地图**不在**游戏内，需要单独下载：

- **精选地图**：我们挑选的 13 张社区作者的地图，形状圆润，纹理经过我们的提升：并非作者最初使用的纹理。它们约 1.1 GB，所以单独提供下载：在游戏的发布页面找名为 `data-<日期>` 的发布（例如 `data-20261117`），每张地图一个 `.zip`，分别解压到游戏文件夹 `assets/levels/drahtseilakt/`。Linux 上还有软件包 `drahtseilakt-levels`（`.deb` 或 `.rpm`）。

在装好精选地图之前，“开始”菜单里的 **精选地图** 只有一个关卡，即随游戏附带的小型 *合成关卡*（包含游戏所有元素的测试关卡）。那 13 张地图只是不在列表里；游戏不会报错，也不缺别的东西。解压后，下次启动就会出现。

它们都属于各自的作者，在此致谢展示。如果作者要求撤下，我们会撤下。

## 您的数据文件夹

设置、成绩、回放和您自己的关卡都保存在一个数据文件夹中：

| 系统 | 数据文件夹 |
|---|---|
| Linux | `~/.local/share/drahtseilakt/` |
| Windows | `%APPDATA%\drahtseilakt\` |
| macOS | `~/Library/Application Support/drahtseilakt/` |
| 便携版 | 程序旁的 `data/` 文件夹（旁边有 `portable.txt` 文件，且不会使用文件夹之外的任何位置） |

其中的 `levels/` 文件夹包含以下文件夹：

| 文件夹 | 内容 |
|---|---|
| `ballance-original/` | 您的原版游戏拷贝，由工具箱放入 |
| `ballance-remaster/` | 重制为 4K 的原版关卡，由 `drahtseilakt-toolbox` 生成 |
| `user-levels/` | 您自己的和下载的地图 |
| `modified/` | 社区对原版关卡的改编（旋转、倒序、隐形）；需要您的拷贝 |

## 规则：一个关卡就是一个文件夹

只有当关卡位于一个有名字的独立文件夹中，且该文件夹内有 **一个 `.nmo` 文件**（或一个开放格式的关卡）**以及描述文件
`level.txt`** 时，它才算一个关卡。直接扔进文件夹的零散 `.nmo`，或没有 `level.txt` 的文件夹，不会显示在列表中。

```
user-levels/
  我的地图/
    我的地图.nmo
    level.txt
    preview.png        （图片，可选）
  第一季/              （分组文件夹：自身不含关卡）
    另一张地图/
      另一张地图.nmo
      level.txt
```

自身不含关卡的文件夹被视为分组文件夹，游戏会查看其内部。不要把两个关卡放进同一个文件夹。

### level.txt

一个纯文本文件，每行形如 `键 = 值`。以 `#` 开头的行是注释。

```
# 我的第一张地图
title = My Map
title.zh = 我的地图
author = 您的名字
version = 1.0
difficulty = 4
```

| 键 | 含义 |
|---|---|
| `title` | 列表中的名称（英文；最多显示 40 个字符） |
| `title.zh`、`title.ru`、`title.de` ... | 其他语言的名称，菜单使用该语言时显示 |
| `author` | 地图作者 |
| `version` | 地图版本 |
| `difficulty` | 难度，1 到 10 的整数；列表按它排序 |
| `order` | 一个数字，使该关卡排得更靠前 |

真正必需的只有 `title`；文件最大 4 KB。

### “关卡文件夹中有些条目有误”

在您的关卡列表中，游戏可能提示有些条目有误。这说明它发现了不符合上述规则的文件夹或文件：零散的 `.nmo`、没有
`level.txt` 的文件夹，或含有多个关卡的文件夹。解决办法：把每张地图放进各自的文件夹，加上至少含一行 `title` 的
`level.txt`，然后重新打开列表。游戏的日志会列出每个被跳过的条目。

最省事的办法是使用 [工具箱](toolbox.md)：它的 *导入地图* 会把整个下载的合集整理成这种形式。
