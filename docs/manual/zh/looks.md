# 外观

**设置、图形** 中的 **外观** 一行决定关卡如何绘制。它只改变画面。物理、游玩、回放和纪录都完全不变。

| 外观 | 您看到的 |
|---|---|
| **原版**（经典） | 圆润的形状配您自己 Ballance 拷贝中的纹理（需要拷贝） |
| **重制版** | 同样圆润的形状，配工具箱放大的 4K 纹理和少许浮雕（需要 `drahtseilakt-toolbox remaster`） |
| **Drahtseilakt** | 我们自己的纹理加圆润的形状，随游戏提供。默认选项 |
| **自选包** | 您放在数据文件夹 `textures/` 中的纹理包 |

下一个开始的关卡会使用新的外观。

## 圆角处理

原版的形状由生硬的棱角构成。Drahtseilakt 会把每张地图上本该圆的东西（球、管道、拱门）做圆，包括从未有过这种处理的社区地图。
方块的边仍保持锐利。工具箱处理过的地图自带圆角；其他地图在加载时处理。这只是画面：球仍沿着原版的形状滚动。

## 回到 2004 年

如果想要原汁原味，请开启模组 **回到2004年**（*设置、扩展、模组*；见 [模组](mods.md)）。它会关闭圆角和放大的纹理，
让关卡按作者制作时的样子绘制，还会给您 4:3 画面中放大成硬像素的低分辨率、远处闪烁的纹理，以及（如果您愿意）帧率上限。
游玩本身不变，回放也完全一致。
