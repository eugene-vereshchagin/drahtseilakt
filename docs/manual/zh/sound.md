# 声音与音乐

*设置、声音* 用于设置音乐和音效（滚动、撞击、坠落、菜单点击声）的音量，范围 0 到 10，还有 **音效主题**：声音和音乐的来源。

| 主题 | 说明 |
|---|---|
| **neuro** | 由 AI 为本游戏制作的音效和音乐，从零合成。默认选项 |
| **system** | 多位作者的开放许可录音；谁做了什么，见游戏的致谢 |
| **original** | 您自己 Ballance 拷贝中的音效和音乐，由工具箱在您的电脑上制成主题（见 [工具箱](toolbox.md)）；之后才会出现 |
| 自选 | 数据文件夹 `sounds/` 中的一个主题文件夹；它缺少的内容取自另一个主题 |

原版的声音从不属于游戏本身：它们只留在您的拷贝中。
