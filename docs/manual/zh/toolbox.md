# 工具箱

**drahtseilakt-toolbox** 是一个独立的程序，在您自己的电脑上为游戏准备关卡。游戏本身只播放其关卡文件夹中的内容；
一切繁重的工作都由工具箱完成。它从不联网，也从不改动您的 Ballance 拷贝。可在 Linux、Windows 和 macOS 上运行。
不带参数启动时会打开窗口；界面有英语、俄语、德语和简体中文。

## 它能做什么

- **导入您的 Ballance 拷贝。** 用路径旁的 **浏览** 和 **镜像** 按钮选择已安装游戏的文件夹或光盘镜像（`.cue`、`.bin`、`.iso`）。
  原版关卡随后出现在游戏的 *开始、经典 Ballance* 中。同一步还会用您拷贝中的音效和音乐生成 **original** 音效主题；
  它们只留在您的电脑上。
- **重制为 4K。** *Make* 按钮会重制原版关卡：形状更圆润，纹理放大 4 倍（倍数可选）。如果 Real-ESRGAN 放大器放在工具箱旁边就使用它，
  否则使用普通的平滑放大。结果保存在 `levels/ballance-remaster/`，供 *重制版* 外观使用（见 [外观](looks.md)）。您的原版文件保持不变。
- **导入下载的地图。** 指定一个装有已解压社区地图合集的文件夹，点击 *Import*：每张地图在 `levels/user-levels/` 中得到自己的文件夹，
  含 `level.txt` 和图片，可直接用于游戏（见 [关卡与文件夹](levels.md)）。再次运行只会添加新的内容。压缩包（`.zip`）不会被打开：
  请先在 `user-levels/` 之外解压。
- **检查地图。** 导入后，它会请游戏试运行每张地图，并在旁边保存一份简短报告，您在关卡列表中可以看到：完全可玩、可玩但有差异、
  可能无法通关，或无法加载。

## 常见步骤

1. 安装工具箱，启动并指向您的 Ballance 拷贝。点击 *Make* 并等待（大纹理耗时较长；进度按关卡显示）。
2. 启动游戏：*经典 Ballance* 现在列出 13 个原版关卡。在 *设置、图形* 中选择您喜欢的外观。
3. 对于下载的地图：解压下载内容，在导入栏选择其文件夹，点击 *Import*。
