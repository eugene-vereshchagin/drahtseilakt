Drahtseilakt（德语意为“走钢丝”）是 **Ballance** 的全新引擎。Ballance 是 2004 年的益智游戏，玩家操控一只球，在深渊上方
狭窄的轨道和桥梁上滚动。玩它并不需要原版游戏：游戏自带一批社区地图，以及自制的音效和音乐（我们精选的 13 张地图需单独下载，见 [关卡与文件夹](levels.md)）。
如果您拥有原版 Ballance，它还能从您自己的拷贝中运行原版的 13 个关卡。

## 安装

从[最新版本](https://github.com/eugene-vereshchagin/drahtseilakt/releases/latest)下载适合你系统的文件：

- **Windows**：安装程序 `…-windows-x86_64-setup.exe`，或便携版 `…-windows-x86_64.zip`（解压到任意位置，运行 `drahtseilakt.exe`）。ARM 电脑请选 `aarch64` 文件。
- **macOS**：`…-macos-aarch64.dmg`（Apple Silicon）或 `…-macos-x86_64.dmg`（Intel）。游戏未签名：第一次请右键点击并选择*打开*。
- **Linux**：便携版 `…-linux-x86_64.tar.gz`（解压后运行 `drahtseilakt`），或软件包。软件包安装需要两个文件：程序本身和它的数据包 `drahtseilakt-data`（我们的部件、声音、模组、本手册和社区地图）：
  `sudo apt install ./drahtseilakt-data_*_all.deb ./drahtseilakt_*_amd64.deb`（Debian、Ubuntu）或
  `sudo dnf install ./drahtseilakt-data-*.noarch.rpm ./drahtseilakt-*.x86_64.rpm`（Fedora）。
- **FreeBSD**（实验性）：`…-freebsd-x86_64.tar.gz`。

安装程序和便携压缩包已包含全部数据。13 张精选地图需单独下载（[关卡与文件夹](levels.md)）。

## 从哪里开始

1. 在主菜单点击 **开始**，选择 **社区地图**（如果已下载，也可选 **精选地图**）。选一个关卡，开始滚球。
2. 按住 **空格** 抬起镜头，观察前方的路；**Shift + 左 / 右** 转动镜头。
3. 卡住了？按 **Esc** 打开暂停菜单，可以在那里重新开始关卡。
4. 想要原版关卡或 4K 纹理？见 [工具箱](toolbox.md)。
5. 想添加下载的地图？见 [关卡与文件夹](levels.md)。
