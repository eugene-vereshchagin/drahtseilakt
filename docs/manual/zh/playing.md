# 游玩

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 | 滚动球（上键为远离镜头方向） |
| Shift + 左 / 右 | 围绕球转动镜头 |
| 空格 | 抬起镜头，俯瞰关卡 |
| Esc | 暂停菜单；在其他菜单中为返回 |
| F11 | 切换全屏 |
| F1 | 打开本手册，菜单中任何位置都可以 |

手柄也可使用：左摇杆或十字键滚动球，肩键转动镜头，下方按键俯瞰，Start 暂停。按键可在 **设置、操作** 中修改：选中一行，
按 Enter，再按下新的按键。*默认* 恢复原版按键，*反转旋转?* 让镜头朝相反方向转。菜单中也可以用鼠标。

## 球与变形器

您从关卡给定的球开始。球有三种，而 *变形器*（轨道上的一个圆环）会把您的球变成另一种：

- **木球** 是全能型，也是大多数关卡开始时的球。
- **石球** 很重：起步慢、难刹住，但在轨道上很稳。
- **纸球** 非常轻：加速很快，但容易被关卡里的风扇和风吹得乱飞。

有些关卡还有第四种我们自制的球，**粘性球**，它会粘住接触到的东西。
每种球的滚动手感不同，所以选之前先看看轨道。

## 检查点、生命与分数

- 关卡分为若干区段。到达区段末尾的检查点后，进度会被保存。
- 掉下去或丢了球，您会带着新球回到最近的检查点。每关开始时有 **3 条生命**；用完后可以重新开始关卡或回到菜单。
- 您从 **1000 分** 开始，分数会随时间递减。沿途可以拾取 **额外分数** 和 **额外生命**。
- 到达终点时，您得到剩余分数、关卡奖励，以及每剩一条生命 200 分。通关后下一关解锁；最好成绩会进入 **最高分** 榜。

## 暂停与重新开始

**Esc** 暂停游戏。暂停菜单提供：继续、重新开始、最高分、设置和退出关卡。重新开始和退出会先确认一次。
每次完成的游玩都会保存为回放。

## 菜单

- **开始** 列出关卡集：*精选地图*、*经典 Ballance*（需要您的原版拷贝）、*Ballance 挑战*（社区对原版关卡的改编，同样需要拷贝）
  以及 *社区地图*（含 *随附* 与 *我的关卡*）。每张地图旁边显示 1 到 10 的难度。
- **设置** 包含 *图形*（窗口大小、垂直同步、云层、全屏和 *外观*，见 [外观](looks.md)）、*操作*、*声音*（音量和音效主题，
  见 [声音与音乐](sound.md)）、*语言*、*扩展* 和 *帮助*（本手册）。
- **语言** 立即切换菜单语言：英语、俄语、德语、简体中文、法语、西班牙语和意大利语。
- **扩展** 开启扩展模式：关卡旁显示最佳时间、更多外观与声音选项，以及 [模组](mods.md)。关闭时，游戏与原版一致。

菜单的每一行都在屏幕的面板上有简短说明。
