# 疑难解答

**没有原版关卡。** *经典 Ballance* 需要您自己的 Ballance 拷贝。请用工具箱导入（见 [工具箱](toolbox.md)），
选择已安装游戏的文件夹或其光盘镜像。请确认工具箱找到了拷贝：它的窗口会显示结果，您数据文件夹中的
`levels/ballance-original/` 也会被填充。

**我的地图不在列表中。** 关卡必须位于自己的文件夹中，含一个 `.nmo`（或开放格式的关卡）和一个 `level.txt`
（见 [关卡与文件夹](levels.md)）。零散的文件或没有 `level.txt` 的文件夹不会显示。把地图放进数据文件夹的
`levels/user-levels/`，再重新打开列表。从终端启动游戏时，日志会列出每个被跳过的条目。

**加载很慢。** 大的 4K 纹理需要时间加载。工具箱处理过的关卡带有显卡能快速读取的纹理形式；如果您用较旧的工具箱重制过，请再运行一次。
工具箱没有处理过的地图会在加载时做圆角，需要片刻。

**画面卡顿或撕裂。** 在 *设置、图形* 中试试更小的窗口，开启 *垂直同步?*，或选择 *Drahtseilakt* 外观。

**关卡无法加载或看起来不对。** 有些社区地图使用了游戏尚不支持的功能。关卡列表中工具箱的报告会说明它发现了什么。
这样的地图也许仍可游玩。

## 我的文件在哪里

在您的数据文件夹中（见 [关卡与文件夹](levels.md)）：

- `settings.txt`：您的设置。
- `replays/<关卡>/`：您游玩的回放（`.replay`）和会话日志（`session-....log`）。
- `screenshots/`：“截图键”模组保存的图片。

## 报告问题

请到项目主页 github.com/eugene-vereshchagin/drahtseilakt（Issues）告诉我们。请写明关卡、发生了什么、您做了什么，
说明您的系统，并附上 `replays/<关卡>/` 文件夹中最新的 `session-....log` 和该次游玩的 `.replay`。
