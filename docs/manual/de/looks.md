# Aussehen

Die Zeile **Aussehen** unter *Optionen, Grafik* wählt, wie Level gezeichnet werden. Es ändert nur das Bild. Physik,
Läufe, Wiederholungen und Rekorde bleiben genau gleich.

| Aussehen | Was Sie sehen |
|---|---|
| **Original** (klassisch) | abgerundete Formen mit den Texturen Ihrer eigenen Ballance-Kopie (braucht die Kopie) |
| **Remaster** | dieselben abgerundeten Formen mit den vergrößerten 4K-Texturen der Toolbox und etwas Relief (braucht `drahtseilakt-toolbox remaster`) |
| **Drahtseilakt** | unsere eigenen Texturen auf abgerundeten Formen, im Spiel enthalten. Die Vorgabe |
| **Eigenes Paket** | ein Texturpaket von Ihnen aus dem Ordner `textures/` in Ihrem Datenordner |

Das nächste Level, das Sie starten, nutzt das neue Aussehen.

## Abrundung

Die Formen des Originals bestehen aus harten Winkeln. Drahtseilakt rundet Gebogenes wie Kugeln, Rohre und Bögen auf
jeder Karte ab, auch auf Community-Karten, die das nie hatten. Kanten von Quadern bleiben scharf. Eine von der Toolbox
vorbereitete Karte bringt ihre Abrundung mit; jede andere wird beim Laden abgerundet. Das ist nur Optik: Die Kugel
rollt auf den Formen des Originals.

## Zurück ins Jahr 2004

Wenn es so sein soll wie früher, schalten Sie den Mod **Zurück ins Jahr 2004** ein (*Optionen, Erweitert, Mods*; siehe
[Mods](mods.md)). Er schaltet Abrundung und vergrößerte Texturen ab, sodass Level so gezeichnet werden, wie ihre Autoren
sie gemacht haben. Dazu gibt er Ihnen eine niedrige Auflösung in groben Pixeln im 4:3-Bild, in der Ferne flimmernde
Texturen und, wenn Sie möchten, eine Bildratenbegrenzung. Der Lauf selbst bleibt gleich, Wiederholungen laufen
identisch ab.
