# Mods

Mods sind kleine Erweiterungen, die das Verhalten des Spiels ändern, etwa ein Timer, eine freie Kamera oder eine
klebrige Kugel. Sie stehen in einer einfachen Textdatei und werden nie als Programme ausgeführt. Mods gibt es im
**erweiterten Modus**.

## Mods einschalten

1. *Optionen, Erweitert*: *Erweiterter Modus?* einschalten.
2. *Mods* öffnen. Links und Rechts schalten den gewählten Mod ein oder aus; Enter öffnet seine Seite mit Optionen und
   Tasten.

Ein Mod, der die Regeln des Laufs ändert (Schwerkraft, klebrige Wände, Sprünge zwischen Sektoren und Ähnliches),
markiert Ihren Lauf als **modifiziert**: Er wird gespeichert, zählt aber nie als Bestzeit oder Rekord. Mods, die nur
das Bild ändern oder Informationen zeigen, lassen Ihren Lauf unberührt.

## Die mitgelieferten Mods

| Mod | Was er macht |
|---|---|
| Zurück ins Jahr 2004 | das Spiel wie auf einem PC von 2004: niedrige Auflösung in groben Pixeln, flimmernde Ferne |
| Verdunkelung | das Level wird dunkel; über der Kugel hängt ein schwaches Licht |
| Verformte Kugel | die Holzkugel verformt sich zufällig, nur als Bild |
| Dynamisches Sichtfeld | das Sichtfeld wird mit der Geschwindigkeit der Kugel weiter |
| Freie Steuerung | die Maus dreht die Sicht, die Pfeile steuern entlang der gedrehten Sicht (modifiziert) |
| Freie Sicht | die Maus dreht die Sicht um die Kugel; eine Taste dreht sie zurück |
| Info-Anzeige | Position, Tempo, übrige Extras, Bilder pro Sekunde und eine Uhr |
| Störung | durchsichtige Lockbälle kreisen um die Kugel |
| Physiklabor | Schwerkraft nach unten und seitlich und Zeitfaktor der Physik ändern (modifiziert) |
| Spielzeit | zählt die Spielzeit je Level und insgesamt |
| Schneller Neustart | eine Taste startet das Level sofort neu |
| Sackstützen | die schwingenden Säcke hängen an Säulen und Masten statt in der Luft (standardmäßig an) |
| Screenshot-Taste | eine Taste speichert das Bild als PNG im Ordner `screenshots` Ihres Datenordners |
| Sprung zwischen Sektoren | Tasten starten das Level im nächsten oder vorigen Sektor neu (modifiziert) |
| Abschnitts-Timer | Laufzeit, echte Zeit und Abschnittszeiten gegen den besten Lauf |
| Sanfte Kamera | die Kamera gleitet in Drehungen wie im Film |
| Startpunkt | eine Taste setzt einen Startpunkt beim Ball, eine andere bringt ihn dorthin zurück (modifiziert) |
| Geisterball | Ihr bester Lauf des Levels rollt als durchsichtiger Ball mit |
| Klebriger Ball | haftet an allem; gegen eine Wand drücken, um sie hochzuklettern (modifiziert) |

Eigene Mods sind möglich: ein Ordner mit einer `mod.txt` im Ordner `mods/` Ihres Datenordners.
