Drahtseilakt ist eine neue Engine für **Ballance**, das Knobelspiel von 2004, in dem man eine Kugel über schmale
Schienen und Brücken hoch über einem Abgrund rollt. Zum Spielen braucht man das Originalspiel nicht: Es kommt mit einer
Auswahl unserer Lieblingskarten, einem Satz Community-Karten sowie eigenen Klängen und eigener Musik. Wer das
originale Ballance besitzt, kann zusätzlich dessen 13 Level aus der eigenen Kopie spielen.

## Wo anfangen

1. Wählen Sie im Hauptmenü **Start** und dann **Ausgewählte Karten** oder **Community-Karten**. Level aussuchen und los.
2. Mit gehaltener **Leertaste** heben Sie die Kamera für einen Blick auf den Weg; **Umschalt + Links / Rechts** dreht
   die Kamera.
3. Festgefahren? **Esc** öffnet das Pausenmenü, dort lässt sich das Level neu starten.
4. Sie möchten die Originallevel oder 4K-Texturen? Siehe [Die Toolbox](toolbox.md).
5. Sie möchten heruntergeladene Karten hinzufügen? Siehe [Level und Ordner](levels.md).
