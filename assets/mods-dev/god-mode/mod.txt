# God mode: the practice tools, gathered in one mod. Free saves, endless lives, seconds back, slow motion, the free
# camera, the sector and tick on screen. A development mod (assets/mods-dev): only a game run with --debug finds it,
# and a release does not ship it. It changes the run: its runs are modded (no level opens, never a best or a
# highscore).

var saved_at 0

on tick
do lives.endless opt.lives

on key rewind
do rewind opt.back

on key save
do save
do set saved_at = run.time

on key load
do load

on key restart
do restart

on key slower
do slower

on key faster
do faster

on key camera
do freecam

on frame
do show top-left sector int run.sector
do show top-left tick int run.tick

on frame
if practice.speed < 1
do show top-left speed int 1 / practice.speed

on frame
if practice.saved
do show top-left saved time saved_at

on frame
if opt.hint
do keys bottom-left
