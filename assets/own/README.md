# The game's own interface files

Our own files for the interface roles the original's copy fills (docs/drahtseilakt/resources.md), laid out as the
original (`3D Entities/...`, `Textures/...`). Nothing here comes from the original. With the extended mode's
Interface switch on "own" the game takes these first and the copy's for what is not here yet. Sounds and music are
not here: they are sound themes, in `assets/sounds/<theme>/`.
